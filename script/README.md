# Projeto OmniChannel Management System

Este projeto integra uma solução de base de dados relacional (MySQL) e não-relacional (MongoDB) para um sistema OmniChannel.

## Conteúdo do Repositório
- `/docs`: Contém o Diagrama Entidade-Relacionamento (DER).
- `/scripts`: Scripts SQL (DDL, DML e PL/SQL), PoC NoSQL (MongoDB) e o backup da base de dados.
